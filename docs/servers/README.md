# Server guides

(creating credentials with least privilege), *secrets*, *config guide*, *verify*, and
*troubleshooting & rotation*.

| Server | Guide |
|---|---|
| GitHub | [github.md](github.md) |
| Netlify | [netlify.md](netlify.md) |
| Firebase | [firebase.md](firebase.md) |

| **All 40+ built-in servers** (Context7, Playwright, Supabase, Sentry, Linear, Stripe, …) | [catalog.md](catalog.md) |
| Anything else | [custom-servers.md](custom-servers.md) |

`wirebay presets` lists the built-in servers from your installed version.
