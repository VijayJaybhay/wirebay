# Server guides

(creating credentials with least privilege), _secrets_, _config guide_, _verify_, and
_troubleshooting & rotation_.

| Netlify                                                                                  | [netlify.md](netlify.md)               |
| Firebase                                                                                 | [firebase.md](firebase.md)             |

| Anything else                                                                            | [custom-servers.md](custom-servers.md) |
