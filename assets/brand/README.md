# wirebay brand assets

| File                           | What                                                                  |
| ------------------------------ | --------------------------------------------------------------------- |
| `wirebay_logo.png`             | **Original** logo (mark + wordmark), transparent, 1170×420            |
| `wirebay_icon.png`             | **Original** icon (mark only), transparent, 1254×1254                 |
| `wirebay_logo_dark.png`        | Logo for dark backgrounds: wordmark recolored to near-white           |
| `wirebay_social_preview.png`   | 1280×640 GitHub social preview (Settings → General → Social preview)  |
| `icon/wirebay_icon_<size>.png` | Square icon, trimmed and evenly padded: 16–512 px (180 = Apple touch) |
| `icon/favicon.ico`             | Multi-size favicon (16–256 px)                                        |

The originals are never edited. Everything else is derived from them, so regenerate derivatives
from the originals rather than editing a derivative. They are not part of the npm package; the
README loads them from GitHub.
